# MovieMatcherWebsite

### Alex Dewolf, Abhie Koirala, Jake Moseley, Zachary Wehbe

## What is it?
The movie matcher website is designed to give you a list of your potential next favorite movies!
The website used to find a student's next movie to watch. The website will show one movie at a time with its rating, genre, and actors, and the user can choose to like or dislike it. The website will then give the user a list of movies that it recommends the user watch.
